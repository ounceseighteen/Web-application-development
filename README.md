# Генератор паролей

Простой веб-сайт для генерации безопасных паролей с системой регистрации и авторизации пользователей.

Функциональность

🔐 Регистрация и авторизация пользователей

🔑 Генерация паролей двух типов сложности:

Простые (буквы и цифры)

Сложные (буквы, цифры и специальные символы)

💻 Адаптивный дизайн для разных устройств

🌐 Доступ с других устройств в локальной сети

Технологии

Backend: Python, Flask

Frontend: HTML, CSS

Хранение данных: JSON файлы

Аутентификация: Сессионная авторизация

Установка и запуск

Установите зависимости:

pip install flask

Запустите приложение:

python Generation.py

Использование

Зарегистрируйтесь или войдите в систему

Выберите сложность пароля:

Простая - буквы и цифры

Сложная - буквы, цифры и специальные символы

Нажмите "Сгенерировать пароль"

Используйте сгенерированный пароль для своих нужд
